## Promotion rule

A row is promoted only when the implementor adopts the behavioral assertion into ordinary discovery, turns it green without weakening the contract, and retains the lowest truthful layer. A stronger equivalent guard may replace the exact staging file only when it proves the same user-visible behavior; record that substitution in this ledger. Current status is intentionally `no` for every new RED because no implementation PR is integrated.
