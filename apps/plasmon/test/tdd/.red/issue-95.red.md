# Issue #95 — selected Desktop filename presentation

## Disposition

**COVERED BY #191 — NO DUPLICATE PACKET.** #191's committed browser geometry
gate directly protects the same current defect boundary: the rename editor
must remain bounded by its FileEntry tile while selected/renaming presentation
may become more readable without changing persisted icon placement.

Existing Desktop label tests and #192 placement gates remain preserved. Do not
stage a second geometry gate with contradictory width/edge policy; implementors
should reconcile the complete #191 acceptance criteria with the #95 readable
selected-label requirement.
