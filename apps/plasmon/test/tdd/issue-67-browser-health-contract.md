# #67 packaged browser health contract

The focused #67 health budget begins with the strict #187 ledger and removes
only Monaco-owned allowances. It must not inherit js-dos (#202), icon (#190),
iframe, audio, GPU, or unrelated Kernel allowances.

**Unexpected failure:** pageerror; unhandled Worker error; console error or
warning containing worker/bootstrap/SecurityError/ORB/CORS/fallback; failed
first-party worker request; non-2xx worker response; Worker handshake timeout;
editor operation that requires the worker failing.

**Temporarily accepted only while the canonical defect is open:** the exact
#67/#200 worker fallback and opaque-origin warnings already recorded by #187,
with the issue and retirement criterion in the allow-rule reason. A visible
editor is not a health exemption.

**Retirement:** after the installed Text+Markdown journey records successful
Worker creation and communication in Chromium and Firefox, remove only these
#67/#200 rules and rerun the same strict journey. #202 rules remain until #202
is independently fixed; no sandbox permission change is an acceptable shortcut.
