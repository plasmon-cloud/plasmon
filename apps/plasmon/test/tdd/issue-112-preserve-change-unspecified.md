# #112 preserve/change/unspecified

**Preserve:** domain controls, Process/Windowing authority, association/opening,
editor/session semantics, Markdown sanitizer, media/runtime sandbox, accessible
loading/error status, app-specific layout.

**Change:** reduce accidental duplicated content chrome and hardcoded theme
values where a shared semantic primitive is accepted; preserve one identity
source per app.

**Unspecified:** wrapper component name, file layout, exact CSS, pixel spacing,
app framework, generic toolbar API, whether every app migrates in one change.
No honest RED is created for structural convergence alone.
