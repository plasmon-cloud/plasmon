# Native/runtime test-layer map

| behavior | truthful layer | why |
|---|---|---|
| MIME/association/handler selection | Bun/headless | deterministic registry/OpenService |
| Process/Window lifecycle | Bun/headless | production authorities, no DOM needed |
| Document save/conflict/dirty-close | Bun/headless | bytes/state/close request |
| app semantic controls | RTL | real React accessibility wiring |
| Markdown sanitize/format model | Bun | pure deterministic output |
| package graph/assets | package | generated output contract |
| Monaco Worker/security/focus | installed Playwright | real Worker/browser/origin |
| Photos fullscreen/decode/geometry | installed Playwright | browser policy/layout |
| Video codec/playback | installed Playwright | native media engine |
| Browser iframe/sandbox | installed Playwright | foreign browsing context |
| js-dos/EmulatorJS runtime | installed Playwright | Worker/WASM/canvas/iframe |
| Review semantic engine | Bun Review workspace | standalone provider domain |
| Review install/persistence | Review Playwright | vanilla Neutron package boundary |
| visual polish/theme | bounded manual/package review | pixels/contrast feel not stable source tests |
