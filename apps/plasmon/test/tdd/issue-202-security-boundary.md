# #202 security boundary

Preserve the current Neutron sandbox and CSP exactly. Do not add
`allow-same-origin`, fullscreen/storage permissions, a top-level escape, vendor
bundle blind patch, fake persistent storage, direct runtime launch, or broad
health allowlist. The future owner may add a narrow capability detection/adaptor
inside the js-dos runtime host, or graceful non-authoritative degradation, only
if it leaves the real local-asset and canonical OpenService boundaries intact.

Retirement is issue-scoped: remove only the two #202 rules in #187 after the
installed runtime has no corresponding errors. Monaco, icons, audio/GPU and
iframe allowances are unrelated.
